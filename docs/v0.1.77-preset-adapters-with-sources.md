所有新增序列均来自厂商公开文档，备注里也写了来源。**旧的占位条目「PacBio 通用接头」「Nanopore 接头」已退役**（那两条是示例占位，不是官方序列）。

## 1. Illumina（二代接头）

骨架（Illumina《Adapter Sequences》文档 / support.illumina.com 寡核苷酸序列页）：

| 元件 | 序列（5′→3′） | 长度 |
|---|---|---|
| P5 | `AATGATACGGCGACCACCGAGATCTACAC` | 29 |
| P7 | `CAAGCAGAAGACGGCATACGAGAT` | 24 |
| ME（Read1 侧 = Read1 测序引物） | `TCGTCGGCAGCGTCAGATGTGTATAAGAGACAG` | 33 |
| ME（Read2 侧 = Read2 测序引物） | `GTCTCGTGGGCTCGGAGATGTGTATAAGAGACAG` | 34 |

结构：

```
i5 引物 = P5 + [8nt i5 index] + ME1   →  70 nt
i7 引物 = P7 + [8nt i7 index] + ME2   →  66 nt
```

入库条目：

- `Illumina P5 overhang` / `Illumina P7 overhang`（只要 overhang 时用）
- `Nextera i5 全长（无 index）` 62 nt / `Nextera i7 全长（无 index）` 58 nt（单样本、无需 index）
- `Nextera i5 引物 S502/S503/S505/S506/S507/S508`（各 70 nt，仅 F 向）
- `Nextera i7 引物 N701–N706`（各 66 nt，仅 R 向）

### ⚠️ index 的方向坑（最容易错的一步）

index 有两个方向，别搞混：

- **合成进引物的**是 Illumina 文档里的「**Bases in Adapter**」列
- **sample sheet 上填的**是「Bases for Sample Sheet」列

对 **i5**，两者同向（S502 = `CTCTCTAT`）；对 **i7**，两者互为**反向互补**：

```
N701  引物里放:  TCGCCTTA
N701  sample sheet 填:  TAAGGCGA   ← 反向互补
```

预置库里放的是**引物里的那个方向**。i7 条目的备注里写了 sample sheet 该填什么。

## 2. 三代（PacBio / ONT）

| 平台 | 条目 | 序列（5′→3′） | 长度 | 出处 |
|---|---|---|---|---|
| PacBio | 通用尾（正向） | `GCAGTCGAACATGTAGCTGACTCAGGTCAC` | 30 | PacBio 16S 全长扩增方案官方 universal tail（二轮用 Barcoded Universal Primers，PN 100-466-100） |
| PacBio | 通用尾（反向） | `TGGATCACTTGTGCAAGCATCACATCGTAG` | 31 | 同上 |
| ONT | 一轮加尾（正向） | `TTTCTGTTGGTGCTGATATTGC` | 22 | ONT 官方 PCR barcoding 协议（SQK-LSK110/LSK114 + EXP-PBC096/PBC001） |
| ONT | 一轮加尾（反向） | `ACTTGCCTGTCGCTCTATCTTC` | 22 | 同上 |

这两套正是「一轮 PCR 给引物加尾、二轮加 barcode」的标准做法——跟你现在做的超多重 PCR 流程一致。

## 4. 同源臂（改为设计要点）

`Gibson 同源臂(示例占位)` 仍是占位序列，备注写清了要点：与载体末端完全同源的 20–30 bp、GC 40–60%、避免与引物 3′ 端互补、自身不发夹。

## 5. 用法

左树：`接头 ▸ index(i5)` 选 S502 → F 端点「插入」→「保存」；`index(i7)` 选 N701 → R 端点「插入」→「保存」。
引物结构预览会显示 `5′-[P5+i5+ME](70nt) - [你的引物] -3′`。
