## 2. 「5′ 附加序列库」对话框重做

按你给的布局重做：

- **左半边**：附加序列列表（库条目）。底部按钮：新增条目…（弹出小表单：名称/分类/序列/方向/备注）、
  编辑…（或直接双击列表项）、删除、上移、下移、设为统一默认、停用统一默认。
- **右半边**从上到下：
  1. **F 端附加序列**（+ 链引物）文本框 + 「添加」
  2. **R 端附加序列**（- 链引物）文本框 + 「添加」
  3. **R1 端附加序列**（read1，优先于 F 端）文本框 + 「添加」
  4. **R2 端附加序列**（read2，优先于 R 端）文本框 + 「添加」
  5. **引物结构**预览（只读）——以上设置生效后实际导出的样子：
     `5′- [附加序列](来源,nt) - [引物序列] -3′`，示例直接取库中该方向第一条真实引物序列。
  6. **保存设置（写入当前 XML）**、**另存为…**、**加载库…**、恢复内置预置。

文本框「添加后可修改」：改完再点一次「添加」即更新；清空后点「添加」= 清除该端。

## 3. 生效规则（谁压谁）

```
逐条设置（右键单条引物 / 5′ 附加设置表格）
  > R1 / R2 端槽（按引物 role 匹配）
  > F / R 端槽（按引物方向匹配）
  > 库条目默认（统一 / F、R 分开下拉）
```

- R1 通常就是 F 向那条引物（read1 从它延伸），所以 R1/R2 比 F/R 更具体——两类都填时 R1/R2 赢。
- 建库场景只填 R1/R2（read1/read2 接头不同）；克隆场景只填 F/R；互不干扰。
- header 仍写 `|tail=<来源>`，槽位写成 `|tail=R1端:XXXXXXXX`（取序列前 8nt）。
