# v0.1.72：5′ 附加序列（Tail）三级作用域

解决三个真实痛点：R1 / R2 接头不同、每条引物的酶切位点不同、F / R 的 5′ hang 不同。
原来只有一个「全局开关」，现在分成三级，逐条压过方向，方向压过统一。

## 优先级（上胜下）

| 级别 | 设置位置 | 存哪儿 | 典型用途 |
|---|---|---|---|
| 1 逐条 | 右键引物 → 引物操作 ▸ 本条 5′ 附加 ▸；或设置对话框表格批量 | 引物字段，随 BED / 自动保存 | 每条酶切位点不同、个别引物单独加标签 |
| 2 方向默认 | 工具条「5′附加」→ F 向 / R 向各选一个 | `~/.igv_primer_tails.xml` | R1 / R2 接头不同、F/R 尾巴不同 |
| 3 统一 | 工具条「5′附加」→ 统一（F/R 相同） | 同上（旧版字段） | 两端加同一个酶切位点 |

补充说明：
- **逐条显式指定时不再受条目的「仅F / 仅R」方向限制**——你点名要它，它就上（全局默认层仍然按方向过滤）。
- 逐条可设「本条不附加」，能挡掉全局默认（比如全局都加接头，唯独对照引物不加）。
- 逐条可填**自定义序列**（不入库），优先于条目名。

## 怎么操作

1. **工具条「5′附加:F:… R:…」按钮** → 打开设置对话框：
   - 上半「全局默认」：单选「统一」或「F / R 分开」，下拉选库条目（可「不附加」）。
   - 下半「逐条设置」：表格列出所有引物（本条设置 / 生效序列 / 来源），可 Ctrl、Shift 多选，
     底部下拉一键应用到选中行；另有「自定义序列…」「清除本条设置」「选中全部 F 向 / R 向」。
2. **右键单条引物 → 引物操作 ▸ 本条 5′ 附加 ▸**：继承全局 / 本条不附加 / 自定义序列 / 按分类（酶切位点、接头、通用引物、标签、同源臂）挑选。
3. **序列库本身的增删改**仍走「设置 ▸ 5′ 附加序列库（增删改）…」，XML 可保存 / 加载 / 修改再保存。

## 导出

- 引物 FASTA、测序读段 FASTA 都按三级作用域解析后拼到 5′ 端。
- header 追加 `|tail=<名称>`；自定义序列写成 `|tail=自定义:SEQ`。
- 逐条设置写进 BED name 的两个新段：`|t<条目名>`（`|t-` = 明确不附加）和 `|x<自定义序列>`，
  导入 BED / FASTA 可原样还原；普通 BED（无 `|` 标记）不受影响。

## 兼容

- 老的 `~/.igv_primer_tails.xml`（只有 `active`）照常工作：统一默认，无需改动。
- 库中条目被删除时，对应的方向默认 / 统一默认自动清空，不会留下幽灵引用。
